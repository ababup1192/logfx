## Builds on Flix 0.76.0

Nothing about the API or the emitted JSON changed. From Flix 0.76.0 on, a module of a package
is not visible to another package (or to its own tests) unless it is declared `pub mod`, so
0.3.2 fails to resolve with `Module 'Logfx.Fields' is not accessible` on that compiler.

- `Logfx.Fields` and `Logfx.Sink` are now `pub mod`. Every `def` in them was already `pub`,
  so nothing that could be called before is different.
- `flix.toml` says `flix = "0.76.0"`.
