#
# AGENTS.md の会話ポリシー:「単語は業界の言葉をそのまま使う（カタカナ・英語のまま。
# 和語へ言い換えない・造語を作らない）。独自の比喩で名付けない。」
#
# ここに載るのは、同じ物を指す業界の語が既にあるのに、別の和語や比喩が併走していた語。
# 1 行 = 「禁止する語<TAB>言い換え<TAB>除外の正規表現（任意）」。# で始まる行は読み飛ばす。
# 除外は、その語を含むだけの別の単語（約束・報道など）を数えないため。
